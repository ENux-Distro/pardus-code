# Pardus Code

Solda yapay zekâ, sağda düzenleyiciniz.

Şu an **nano** bölmesine bakıyorsunuz. Solda **opencode** yapay zekâ aracı var —
ondan kod yazmasını, açıklamasını, yeniden düzenlemesini ya da hata ayıklamasını
isteyin; bu projedeki dosyaları doğrudan düzenleyebilir.

## Kısayollar

| Tuşlar                       | İşlev                                          |
|------------------------------|------------------------------------------------|
| `Ctrl-R` ardından ok tuşları | Bölmeleri yeniden boyutlandır (bitirmek için Esc/Enter) |
| `Ctrl-O`                     | İki bölmeyi yer değiştir (tarafları değiştir)  |
| `Ctrl-F`                     | Dosya bul — ya da yeni bir ad yazıp oluştur    |
| `Ctrl-T`                     | Alt tarafta terminal aç/kapat (derle, hata ayıkla, çalıştır) |

## nano içinde

| Tuşlar     | İşlev                  |
|------------|------------------------|
| `Ctrl-S`   | Kaydet                 |
| `Ctrl-X`   | Tamponu kapat / çık    |
| `Ctrl-G`   | Satıra git             |
| `Ctrl-W`   | Dosyada ara            |
| `Alt-<` / `Alt->` | Önceki / sonraki açık dosya |

Bu dosyayı silip kodlamaya başlayın. İyi eğlenceler.
