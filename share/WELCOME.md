# Pardus Code

AI on the left, your editor on the right.

You're looking at the **nano** pane. The **opencode** AI agent is on the left —
ask it to write, explain, refactor, or debug code, and it can edit files in this
project directly.

## Shortcuts

| Keys                      | Action                                   |
|---------------------------|------------------------------------------|
| `Ctrl-R` then arrow keys  | Resize the panes (Esc/Enter to finish)   |
| `Ctrl-O`                  | Swap the two panes (change sides)         |
| `Ctrl-F`                  | Find a file — or type a new name to create it |
| `Ctrl-T`                  | Toggle a terminal across the bottom (compile, debug, run) |

## In nano

| Keys      | Action            |
|-----------|-------------------|
| `Ctrl-S`  | Save              |
| `Ctrl-X`  | Close buffer/exit |
| `Ctrl-G`  | Go to line        |
| `Ctrl-W`  | Search in file    |
| `Alt-<` / `Alt->` | Previous / next open file |
